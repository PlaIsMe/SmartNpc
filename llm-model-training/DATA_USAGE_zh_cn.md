# Active training data

Generated by import_my_chats.py/list_scenarios.py; counts describe prepared data, not trained weights.

Edit [data/my_chats_zh_cn.toml](data/my_chats_zh_cn.toml), then run `python scripts/import_my_chats.py --language zh_cn`.

Every block shows `split`. Only train rows update model weights. Validation measures training; frozen test rows are read-only mirrors and are never trained.

An `npc` reply list expands to one example per alternative with shared context/action/emotion. Counts below include every alternative; they are not TOML block counts.

Training source: **983 blocks**, with **10 replies minimum per block**. Alternative replies share situations; they are not independent evaluation cases.

All currently offered action types have training labels. START_NPC_CONVERSATION is reserved and not offered as a model action. Attack/retaliation, teleportation, unrestricted building and trading remain unsupported.

`data/clean/my_chats_zh_cn.jsonl`, `data/train_zh_cn.jsonl` and `data/validation_zh_cn.jsonl` are generated outputs. Starter/event/witness archives are historical sources and are not appended.

The eight Chinese frozen examples are a separate localized evaluation version; they are not an independently verified quality benchmark. Their visible TOML mirrors cannot be edited into training. A larger evaluation set is still needed for dialogue-quality claims.
