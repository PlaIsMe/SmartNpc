Smart NPC supplies its own JNI bridge (native/llama in the Smart NPC source).
The native library is built from the pinned upstream source with CPU support;
OpenMP, executable tools, server and subprocess support are disabled.
The upstream release is selected by llama_version in gradle.properties.
